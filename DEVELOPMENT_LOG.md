# Aegis Round 2 Development Log

The organizing committee requires at least one meaningful commit every hour during the Round 2 build window.

## Commit policy

- Commit only genuine implementation, testing, documentation, or deployment progress.
- Do not create fake or empty commits merely to satisfy the clock.
- Push each hourly checkpoint to the public GitHub repository.
- Add one organizer account as collaborator: `problemshooter` or `Sohamore`.
- Stop all commits and merges before the official submission deadline.
